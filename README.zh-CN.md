# Pisces

[English](./README.md)

一套面向两个长期运行、独立 agent 的参考架构，包含持续记忆，并以 Cordis 插件集实现。

[![CI](https://github.com/epigrove/pisces/actions/workflows/ci.yml/badge.svg)](https://github.com/epigrove/pisces/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

## 这是什么

Pisces 在同一套 Cordis 插件系统上运行两个独立 agent。二者各自拥有记忆、情绪、人设和判断，通过文件与通道协作。

这些逻辑都在插件中，不依赖托管记忆服务。通道只是传输层，不是 agent 身份；换掉通道，agent 仍然是同一个。

## 30 秒看懂设计

### 衰减

记忆的当前权重按年龄现算。半衰期为 40 天时，α = 0.1867；α 越小，衰减越慢。这里使用幂律曲线而非指数曲线，因此权重永远不会归零。

| 经过时间 | 权重 | 状态 |
| ---: | ---: | :--- |
| 0 天 | 1.0000 | 正常显示 |
| 1 天 | 0.8786 | 正常显示 |
| 7 天 | 0.6783 | 正常显示 |
| 40 天 | 0.5000 | 正常显示 |
| 120 天 | 0.4085 | 正常显示 |
| 400 天 | 0.3267 | 正常显示 |
| 2000 天 | 0.2420 | 变淡 |

权重低于 0.1 时不再主动注入，但账本中的记录永远保留。

### 出口判定

| 文本 | `allow()` 结果 | 原因 |
| --- | --- | --- |
| `#静默#` | 拦截 | agent 显式声明本轮不说话 |
| 今晚吃点啥 | 放行 | 正常聊天 |
| （凌晨，脑子木……） | 放行 | 不再按括号形状拦截 |
| 这次没事，没动静 | 放行 | 不再按空转小结的形状拦截 |
| 给你打八分 | 放行 | 正常夸人，数字不应被误伤 |
| v2 那些分数我先记着 | 放行 | 不再按内部专名的形状拦截 |

`allow()` 只硬拦静默词和重复的退场语句。括号草稿、空转小结和内部专名不按内容形状过滤；它们依靠提示词自律，并由 `dsh-koi-audit` 事后记录。详见 [docs/CHANNEL.md](./docs/CHANNEL.md)。

### 三个设计取舍

- **只增不删：** 账本永不重写。检索时按当前相关性排序，历史保持完整。
- **幂律现算：** 需要时按年龄和半衰期计算重要性，不保存会过期的分数，避免第二真相源。
- **过期只打标：** 淡出的记忆由侧车记录状态，账本中的原始行不改也不删。

| 包名 | 用途 | 有测试 |

## 快速开始

需要 Node.js 22 或更高版本，以及 pnpm。

```bash
./install.sh                   # 安装依赖，执行静态检查与全部测试
node examples/walkthrough.mjs  # 三十秒看懂设计
```

示例脚本不写文件，也不连接服务。接着阅读[快速开始](./docs/QUICKSTART.md)与[通道接入](./docs/CHANNEL.md)。

## 状态

Pisces 是 pre-1.0 参考实现（`0.1.0`）。运行时要求 Node.js 22 或更高版本；CI 使用 Node.js 24。上面的包数量来自当前仓库结构。

仓库隐私检查由 `tools/privacy-scan.mjs` 负责，与 CI 和公开副本导出使用同一脚本。`ops/report-leaks.sh` 只汇总运行时外发内容，不扫描仓库。

## 发布

这个仓库就是源头。发布 = 提交并推送到 `main`；CI 会跑完整测试套件加 `tools/privacy-scan.mjs`。

保持工作树里没有真实身份和部署路径：扫描器默认做格式检查，配置 `PRIVACY_DENYLIST` secret
（逗号分隔的名字）后 CI 还会做精确匹配检查。推送前可以本地先跑一遍：

```bash
node tools/privacy-scan.mjs --root .
```

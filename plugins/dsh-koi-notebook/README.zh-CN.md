# dsh-koi-notebook

中文 | [English](./README.md)

把长篇技能、事件经过和机制状态放在常规记忆注入之外保存。

## 它做什么

- 每篇正文追加为独立 Markdown 文件，元数据追加到 JSONL 索引。
- 只使用调用方选定的三个宽泛类别：`skill`、`event`、`state`。
- 返回包含标题、触发条件、原字关键词和 id 的自足指针。
- 按标题、标签和摘要列出或搜索笔记，默认不包含已归档项。
- 读取整篇、指定小节；正文超过 4,000 字时先给分节目录。
- 通过追加索引更新来归档或恢复笔记，正文始终可读。

## 设计思路

- **笔记本必须独立于记忆，因为它的内容不能每轮注入。** agent 没有通用写文件入口；把长篇步骤或事件塞进普通记忆会占注入预算，还会衰减。笔记本默认零注入，只有明确打开时才读取。
- **指针必须扛住存储层截断。** 记忆条目可能在约 100 字处被裁，尾部 id 会丢。`pointerOf()` 完整保留 id，并把标题、触发条件和关键词压到 96 字内，使记忆注入后索引仍然可用。
- **索引只追加，保留历史。** 归档写入新的 `{id, archived: true}` 行，不回头改原元数据。读取按 id 合并、后写覆盖先写，恢复也只是一条新追加，任何来源记录都不会消失。
- **读取必须受限。** 超过 4,000 字的整篇只返回分节目录和第一节；指定小节同样最多 4,000 字，并明确标记截断。

## 配置

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `dir` | `<KOI_HOME>/.koi/notebook` | 索引与 Markdown 正文目录。 |
| `KOI_HOME` | 用户主目录 | `dir` 为空时的基础目录。 |

## 接口

| 名称 | 类型 | 作用 |
| --- | --- | --- |
| `koi-notebook` | 插件 id | 包导出的挂载名。 |
| `tools` | 注入服务 | 笔记本工具注册所必需。 |
| `note_save` | 工具 | 写入正文和元数据行，并返回指针。 |
| `note_archive` | 工具 | 为指定 id 追加归档或恢复状态。 |
| `note_open` | 工具 | 列出、搜索或读取一篇笔记或小节。 |

## 验证

在仓库根目录运行：

```bash
node plugins/dsh-koi-notebook/test-note-open.mjs
```

测试逐条打印 `✅` 或 `❌`，结束时输出 `N 通过 / 0 失败`；全部通过时退出码为 `0`。

## 说明 / 限制

- 笔记内容不会自动注入，也不会衰减。
- 搜索只对标题、标签和摘要做字面子串匹配，不搜索正文语义。
- `note_save` 先写正文、再写索引；两次写入之间磁盘故障可能留下孤立 Markdown 文件。
- 坏索引行会跳过并写日志计数，但不会原地修复索引。
- 归档只让笔记从默认清单隐藏，不删除也不修改正文。

# dsh-koi-affect

中文 | [English](./README.md)

维护 agent 正在变化的内部状态：精力、多维心情、时间语境，以及回想后短暂留下的余味。

## 它做什么

- 跟踪 0–100 的精力，并让它缓慢趋近当前时段的目标值。
- 每个本地自然日重置一次精力，并支持小憩、睡眠、整理等 `rest` 恢复动作。
- 追加带符号强度、原因和可选曲线的具名心情维度。
- 分别计算每个活跃维度，使“烦躁”和“松快”能同时存在，而不是抵消成一个总分。
- 在 order `96` 注入当前时间、时段语气、精力、上一位说话人和活跃心情。
- 回忆旧情绪证据，只影响这次回忆的措辞，不再写入新的持久情绪事件。

## 设计思路

- **本包只管当前状态，不管社会判断。** 喜恶、描述和好感归 `dsh-koi-lexicon`。这里只保留“我现在怎么样”，避免两个提示词段对同一段关系给出不同数值。
- **心情必须多维，而且由 agent 自己命名。** 单个 0–100 分会抹平混合感受；独立维度可以同时保留“烦”和“松快”。入站不再靠关键词猜情绪，只有 agent 判断事件确实影响心情时才调用 `feel_dimension`。
- **数值由追加记录现算。** `affect.json` 和 `mood-dims.json` 保存带时间戳的证据，活跃心情按需重算。默认心情半衰期是 36 小时，约 20 天到达显示阈值。
- **精力跟随时段，而不是永久下滑。** 数值向当前时段目标收敛并夹在有限区间，避免聊久了就“永远疲惫”，同时保留深夜较低的基线。

## 配置

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `dir` | 解析后的 KOI 数据目录 | affect 与心情默认文件的基础目录。 |
| `file` | `<dir>/affect.json` | 精力、跨日状态和旧 affect 字段。 |
| `ownerOid` | `KOI_OWNER_OID8` 或 `owner000` | 该 id 的发言不触发 affect 评分。 |
| `moodDimsFile` | `<affect 文件目录>/mood-dims.json` | 具名心情维度存储。 |
| `lexiconFile` | `<dir>/lexicon.json` | `recall_mood` 使用的人物来源。 |

## 接口

| 名称 | 类型 | 作用 |
| --- | --- | --- |
| `koi-affect` | 插件 id | 包导出的挂载名。 |
| `tools` | 注入服务 | affect 工具注册所必需。 |
| `session/event` | 事件订阅 | 跟踪最近一位真人说话人。 |
| `system-prompt/assemble` | 事件订阅 | 结算精力和残留，再加入心情段。 |
| `koi:mood`，order `96` | 注入段 | 当前时间、状态、精力、说话人和活跃维度。 |
| `feel_dimension` | 工具 | 追加一条具名心情观察。 |
| `rest` | 工具 | 执行小憩、睡眠或整理后的精力恢复。 |
| `request_mood_tuning` | 工具 | 排队申请修改默认心情半衰期。 |
| `recall_mood` | 工具 | 回想旧 affect 事件和 V3 心情维度。 |

## 验证

在仓库根目录运行：

```bash
node plugins/dsh-koi-affect/test-mood-dims.mjs
```

测试逐条打印 `✅` 或 `❌`，结束时输出 `N 通过 / 0 失败`。全部通过时退出码为 `0`。

## 说明 / 限制

- `request_mood_tuning` 只追加到 `pending-tuning.jsonl`；运维方批准前不会改变生效曲线。
- 旧文件中的单值 mood 可能为兼容而保留，但插件不再写入或注入它。
- 旧残留记录存在时仍会结算，但当前 `recall_mood` 不会再创建新的持久残留条目。
- 心情注入要求宿主的提示词组装对象包含 `sections` 数组。

# dsh-koi-decay

中文 | [English](./README.md)

为记忆、印象、情绪和可见性判定提供共享的衰减数学与记录索引基础。

## 它做什么

- 用 `weight(elapsedDays, alpha)` 计算 `w(t) = (t + 1)^(-alpha)`，并把半衰期或落灰阈值换算成 `alpha`。
- 用并集概率公式合并正负证据，避免线性求和无限突破边界。
- 把旧式平铺记录和新式记录信封归一成同一种内存结构。
- 在独立侧车索引中记录过时标记和召回时间，不改写只追加的记忆账本。
- 维护账本指纹和刷新审计，用于发现绕过正常写入路径的修改。
- 共享人物键、当天被提到状态和短期记忆窗口等记录契约。

## 设计思路

- **划清依赖边界。** 原先多个插件通过相对路径借用 lexicon 的衰减代码，单独安装或移动目录就会解析失败。把数学下沉为独立包后，所有消费者都按包名依赖，不再绑定某个插件的目录。
- **选幂律，不选指数或对数。** 指数曲线缺少长尾，旧对数公式又会让刚写下的内容掉得最快。`(t + 1)^(-alpha)` 开头平缓、尾部很长，符合“旧记录仍应能被回想”的目标。
- **权重永不归零。** 归零会让刻意 recall 彻底失效，也会把“暂时不注入”偷换成“删除”。系统用 `SHOW_THRESHOLD = 0.1` 和 `FADE_THRESHOLD = 0.3` 控制显示，不靠把数据算成零来控制上下文。
- **半衰期语义写死。** `halfToCurve(H) = ln(2) / ln(H + 1)`，`H` 就是权重掉到一半的时间；其中的 `+1` 是曲线的时间原点偏移，不是额外多保留一天。`curveForZero(d)` 求的是权重降到 `0.1` 的那天；到达这条线表示退出注入，不表示删除。
- **并集概率防止重复把分数推满。** `1 - product(1 - a_i)` 永远小于 `1`。几条中等证据会变强但不会无限叠加，正负证据也先分别累积再相减。
- **账本与索引承担不同职责。** 记忆账本只追加，过时和召回状态是 `medium.index.json` 里的派生数据。索引坏了可以重算；索引写入也绝不能用一个空对象覆盖损坏的原始索引。
- **完整性要可见。** 指纹会比较行数、字节数和 SHA-256 与基线的差异。它能发现账本被旁路改写，但不能证明刷新后的基线在语义上一定正确。

## 配置

本包不读取插件配置键。

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| （无） | - | 行为由导出的常量和函数参数控制。 |

## 接口

| 名称 | 类型 | 作用 |
| --- | --- | --- |
| `weight`, `score`, `accumulate` | 函数 | 计算时间权重和合并后的证据值。 |
| `halfToCurve`, `curveForZero`, `alphaFromHalfLife`, `dayAtWeight` | 函数 | 在人类可读时间、`alpha` 和阈值日期之间换算。 |
| `DEFAULT_HALF_DAYS`, `SHOW_THRESHOLD`, `FADE_THRESHOLD`, `REST_DAYS`, `SHORT_MAX_ITEMS` | 常量 | 共享的时间与可见性默认值。 |
| `normalizeRecord`, `hiddenReason`, `shouldSkipComputation`, `validateWrite` | 函数 | 归一、判断和校验记录信封。 |
| `personKeyOf`, `isEmptyPerson`, `markMentioned`, `isMentionedToday` | 函数 | 应用共享的人物键与“被提到”语义。 |
| `readIndexResult`, `writeIndex`, `touch`, `checkLedger`, `recordLedger` | 侧车导出 | 读取及原子更新派生索引和账本指纹。 |

## 验证

在 Pisces 仓库根目录运行：

```bash
for f in plugins/dsh-koi-decay/test-*.mjs; do node "$f" || exit 1; done
```

每条断言输出 `✅` 或 `❌`，结束时输出 `N 通过 / 0 失败`。全部通过时进程退出码为 `0`。

## 说明 / 限制

- 这是库包，不是挂载插件：没有 `apply()`、插件 id、配置 schema、工具或提示词注入。
- 侧车通过临时文件替换写入，但没有跨进程锁；多个写入者仍可能竞争。读取时会保留未知索引桶，降低误删其它桶的风险。
- 指纹只能发现账本与基线之间的漂移，不能发现“内部自洽但内容错误”的重写。
- `stabilityToAlpha()` 和 `legacyHalfToAlpha()` 是迁移兼容入口；它们保留旧行为，不代表新曲线设计。
